Privacy Policy – Szybki Fakt Publisher

Last updated: 16 November 2026

What data the tool uses. When the channel owner logs in with TikTok, the tool receives an access token and the basic profile information allowed by the user.info.basic scope. It uses the video.publish scope only to upload the owner's own videos. The tool also uploads the owner's own videos to the owner's own YouTube channel using the YouTube Data API (scope youtube.upload).

Where data is stored. Access tokens are stored only on the owner's own computer, in local files. They are not sent to any server other than the official TikTok and Google APIs.

Data of other people. The tool does not collect, store or share data of any other users.

Sharing. No data is sold or shared with third parties.

Deleting data. The owner can delete the local token files at any time or revoke access in TikTok and Google account settings.
